# 讲题质量人工评分表（项目书 §6）

每周随机抽 10 题，每题按 5 维度打分（1–5 分）。上线门槛：**均分 ≥ 4**。

| 维度 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 正确性 | 有知识性错误 | 结论对但过程有瑕疵 | 完全正确 |
| 步骤完整性 | 跳步严重 | 偶有跳步 | 每一步有依据 |
| 引导性 | 直接给答案 | 部分引导 | 全程追问、不给答案 |
| 语气 | 生硬/说教 | 一般 | 耐心、肯定做对部分 |
| 举一反三质量 | 无关题 | 同考点但难度偏差大 | 同考点同难度 |

## 记录模板

| 日期 | 题目ID | 正确性 | 步骤 | 引导 | 语气 | 变式 | 均分 | 问题备注 | 是否需修提示词 |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |

## 使用说明

1. 打开产品，让模型引导讲一道题，完整走完「引导 → 3 轮追问 → 解锁讲解 → 举一反三」
2. 逐维度打分并记录问题
3. 出现 3 分及以下：在备注里写明原因，回到 `tutor/prompts.py` 调整对应提示词
