# 真题采集指南（项目书 W1-2）

## 原则（合规红线，项目书 §8）

- 真题：只用 **省级教育考试院官方发布** 的历年中考真题（官网 / 官方公众号 / 官方出版物）。
- 模拟题：**只有教育局/考试院官方公开组织的一模二模等可用**。商业教辅机构（万唯、金考卷等）的模拟题是受版权保护的商业内容，不是开源资料，一律不收。
- 可多省份录入：学生在软件里可选省份，练题时随机混排不同省份的题。
- 只录 **函数/代数类压轴题前两问 + 中档易错题**；几何图题二期再议（首期无识图能力）。

## 步骤

1. 选定省份（建议所在省）→ 搜索「XX省教育考试院 中考真题」
2. 下载近 5 年公开真题
3. 挑选题目 → 录入 `data/question_bank.json`：
   - 新增条目：`id` 顺序编号，`status` 置为 `"ready"`
   - 必填字段：`province`（省份名，如「广东」）、`source_type`（真题 / 模拟题）、`year`、`type`、`difficulty`
   - `question` 用纯文本 + 简易记号（如 `x^2`、`\sqrt{2}`），公式尽量简单
   - `official_answer` 抄录官方答案
4. 小批量试抽检（先 2 题确认单题成本）：
   ```
   python -m quality.run_check --n 3 --limit 2
   ```
5. 批量抽检，**正确率 ≥95% 的题目方可上线讲题**：
   ```
   python -m quality.run_check --n 3 --limit 50
   ```

## 录入格式

见 `question_bank.json` 中 demo 条目，把 `status` 改为 `"ready"` 即参与抽检。

## 预算提醒

- 日限额 3 元、总预算 180 元（环境变量 `TUTOR_DAILY_CAP` / `TUTOR_API_BUDGET` 可调）
- 抽检一次调用（解题+对拍）约消耗 0.001–0.01 元，按每日限额控制批量规模
- 超支即停是设计行为，不是故障
